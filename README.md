# Hotel Management System — MERN Stack

A full-stack web application for managing hotel rooms, guests, bookings, and payment records.

## Technologies Used

- MongoDB Atlas
- Express.js
- React.js
- Node.js
- Mongoose
- Vite

## Project Structure

```text
Hotel-Management-System-MERN/
├── client/       # React frontend
├── server/       # Node.js and Express backend
└── README.md     # Project documentation
```

## Features

- Room management
- Guest management
- Booking management
- Payment record management
- REST API routes
- MongoDB data models

## Requirements

- Node.js and npm
- MongoDB Atlas account or a MongoDB instance
- Visual Studio Code

## Setup

### Backend

```bash
cd server
npm install
```

Configure your MongoDB connection using the environment variable expected by `server/server.js`. Keep your credentials private.

Start the backend using the script defined in `server/package.json`.

### Frontend

Open another terminal:

```bash
cd client
npm install
npm run dev
```

Open the local URL shown in the terminal.
